A family or collection page embeds a JSON blob describing every style, read through a self-hosted CORS proxy since fonts.adobe.com doesn't send the headers a browser needs to fetch it directly. Each font's actual file then comes from a Typekit preview endpoint (use.typekit.net/pf/tk/...) — the same one fonts.adobe.com itself loads to render live specimens with @font-face, and unlike a normal embedded Typekit kit, it isn't restricted to an allow-listed domain.

Based on beemilkz/typerip (originally by Jeremy Clark).
