    Everything happens on-device via the browser's built-in Web NFC API — nothing is ever uploaded. Web NFC only exposes a tag's serial number and any NDEF message it carries, not low-level chip details, so the card family and manufacturer shown here are best-effort guesses from that serial number, not a certain identification.
