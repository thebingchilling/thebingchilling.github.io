    Files travel directly between the two browsers over WebRTC, encrypted automatically (DTLS) — plus a quick check using your code so both sides confirm they agree before anything is offered. A small free public broker (PeerJS) helps the two browsers find each other and can relay traffic when a direct path isn't possible; it only ever sees a one-way hash of your code, never the code itself, and never the file. This site has no server of its own. Both sides need to be online at the same time, and a code stops working once its tab is closed.
